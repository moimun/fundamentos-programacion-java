
# Tema 02. Programación estructurada

En este tema aprenderemos cómo organizar las instrucciones de un programa para que pueda realizar diferentes tareas siguiendo un orden determinado.

Estudiaremos los algoritmos, que permiten diseñar los pasos necesarios para resolver un problema, y las estructuras de control que utilizamos en Java para modificar el orden de ejecución de las instrucciones.

## Contenidos del tema

### 1. Algoritmos

En este apartado conoceremos qué es un algoritmo y cuáles son las fases que se siguen para desarrollar una aplicación informática.

Contenidos principales:

- Definición del problema.
- Diseño del algoritmo.
- Implementación del programa.
- Verificación y pruebas.
- Puesta en marcha y mantenimiento.

[Consultar el apartado de Algoritmos](algoritmos.md)

### 2. Estructuras de selección

Las estructuras de selección permiten ejecutar diferentes instrucciones dependiendo de si se cumple o no una determinada condición.

Contenidos principales:

- Estructura `if`.
- Estructura `if/else`.
- Estructuras de selección múltiple.
- Instrucción `switch`.

[Consultar las estructuras de selección](estructuras-seleccion.md)

### 3. Estructuras de repetición

Las estructuras de repetición permiten ejecutar un conjunto de instrucciones varias veces, mientras se cumpla una condición o durante un número determinado de repeticiones.

Contenidos principales:

- Bucle `while`.
- Bucle `do/while`.
- Bucle `for`.
- Control de las repeticiones.

[Consultar las estructuras de repetición](estructuras-repeticion.md)

---

## Objetivos de aprendizaje

Al finalizar este tema podremos:

- Comprender qué es un algoritmo.
- Conocer las fases del desarrollo de un programa.
- Diseñar soluciones antes de comenzar a programar.
- Utilizar condiciones para controlar la ejecución de instrucciones.
- Realizar repeticiones mediante diferentes tipos de bucles.
- Aplicar las estructuras de programación en Java.
