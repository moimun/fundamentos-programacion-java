

# Tema 03. Arrays y cadenas

En este tema aprenderemos a trabajar con arrays en Java, que permiten almacenar varios valores del mismo tipo utilizando un único identificador.

Veremos cómo declarar e inicializar arrays, cómo acceder a sus posiciones, cómo almacenar datos introducidos por el usuario y cómo realizar diferentes operaciones utilizando sus elementos.

También estudiaremos los arrays multidimensionales, que permiten organizar la información mediante filas y columnas.
