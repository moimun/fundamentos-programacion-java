
# Fundamentos de Programación en Java

Bienvenido a la documentación de **Fundamentos de Programación en Java**.

En esta web se recogen los conceptos fundamentales de programación, desde la introducción a los programas informáticos hasta el uso de estructuras de datos como los arrays.

El objetivo es conocer los fundamentos de la programación y aprender a aplicarlos mediante el lenguaje Java.
